# Чекпойнты дорожной карты

[Обзор дорожной карты](../ROADMAP.md) · [Прогресс в GitHub Issues](https://github.com/starsinc1708/mediadeka/issues/1)

Используйте эти чекпойнты при ревью и проверке готовности. Результаты проверок отмечайте в соответствующей задаче GitHub.

## Ближайшие функции

### Трансляция музыки на телевизор

[Задача #2](https://github.com/starsinc1708/mediadeka/issues/2)

#### Первый сценарий — UPnP/DLNA

- [ ] Меню «Устройство вывода» находит совместимый MediaRenderer и показывает имя выбранного устройства.
- [ ] Локальный трек запускается на реальном устройстве. Текущая очередь сохраняется при переключении вывода.
- [ ] С плеера работают пауза, следующий трек и перемотка на устройстве с поддержкой перемотки.
- [ ] После отключения устройства очередь можно продолжить на компьютере с последней известной позиции.

#### Следующее расширение

- [ ] Google Cast проверен на совместимом устройстве. Сетевые источники добавляются по одному после проверки каждого адаптера на реальном устройстве.

[Спецификация UPnP MediaRenderer](https://openconnectivity.org/developer/specifications/upnp-resources/upnp/mediaserver4-and-mediarenderer3/) · [Google Cast SDK](https://developers.google.com/cast/docs/overview)

### Управление воспроизведением из Windows

[Задача #3](https://github.com/starsinc1708/mediadeka/issues/3)

- [ ] Системная панель показывает название текущего трека, обложку и фактическое состояние воспроизведения.
- [ ] Пауза, продолжение и переключение трека работают из системной панели и с медиаклавиш при свёрнутом приложении.
- [ ] При переключении трека панель обновляет метаданные вслед за плеером.

### Автообновление локальной медиатеки

[Задача #4](https://github.com/starsinc1708/mediadeka/issues/4)

- [ ] Выбранные папки остаются подключёнными после перезапуска.
- [ ] Новые и переименованные файлы отражаются в медиатеке после обновления.
- [ ] При отключении диска сохраняются плейлисты и история. После его возврата записи снова доступны.

## Выпуски на других платформах

- [ ] Локальный трек можно найти в медиатеке, добавить в очередь и воспроизвести через выбранный аудиовыход.
- [ ] Панель «Исполняется» показывает текущий трек и позволяет управлять воспроизведением.

## Следующие функции и расширения

### Звук и непрерывное воспроизведение

[Задача #9](https://github.com/starsinc1708/mediadeka/issues/9)

#### Следующие функции

- [ ] Концертный или концептуальный альбом проигрывается без пауз между соседними треками.
- [ ] Для обычной очереди можно включить плавное сведение соседних треков.
- [ ] ReplayGain выравнивает громкость треков с подходящими тегами. Режим альбома сохраняет разницу громкости между композициями.

#### Дальнейшее расширение

- [ ] Параметрический эквалайзер сохраняет пресеты и автоматически выбирает настроенный пресет при смене аудиовыхода.
- [ ] Таймер сна останавливает воспроизведение через выбранное время или в конце текущего трека.

### Мини-плеер, системный трей и обновления

[Задача #10](https://github.com/starsinc1708/mediadeka/issues/10)

#### Следующая функция

- [ ] В отдельном компактном окне видны обложка, название, прогресс и управление. Размер и положение восстанавливаются после перезапуска.

#### Дальнейшее расширение

- [ ] Из системного трея можно поставить трек на паузу, переключить трек, открыть окно и выйти из приложения.
- [ ] Приложение показывает текущую и новую версии и список изменений. Подлинность установщика проверяется перед запуском. Для сборок из пакетного менеджера доступна его штатная команда обновления.

### Плейлисты, история и рекомендации

[Задача #11](https://github.com/starsinc1708/mediadeka/issues/11)

#### Следующие функции

- [ ] Умный плейлист сохраняет правила по источнику, исполнителю, истории и отметкам «Нравится» и обновляется вместе с медиатекой.
- [ ] Локальный плейлист экспортируется в M3U8 с относительными путями. При повторном импорте сохраняются порядок и сведения о недоступных файлах.

#### Дальнейшее расширение

- [ ] Из одного меню можно изменить отметку «Нравится» и добавить трек в несколько плейлистов или убрать его из них.
- [ ] Видимость собственного плейлиста можно изменить там, где это поддерживает сервис. Первый сценарий — Яндекс Музыка.
- [ ] Статистика показывает время воспроизведения по неделям, популярные треки и рейтинг исполнителей за выбранный период.
- [ ] Список «Меньше такого» показывает скрытые треки и исполнителей и позволяет отменять отметки при поддержке сервиса.

### Подключаемые источники и совместное прослушивание

[Задача #12](https://github.com/starsinc1708/mediadeka/issues/12)

- [ ] Первый OpenSubsonic-сценарий проверен с Navidrome. Работают поиск, альбомы, плейлисты и воспроизведение.
- [ ] Для Apple Music, TIDAL и Deezer поиск и воспроизведение добавляются поэтапно в пределах возможностей каждого сервиса.
- [ ] Для Spotify Connect можно выбрать удалённое устройство, перенести на него воспроизведение и отрегулировать громкость.
- [ ] Участники закрытой сессии по приглашению видят общую очередь и синхронно слушают треки через собственные подключения к сервису.

### Настройки и источники текстов песен

[Задача #13](https://github.com/starsinc1708/mediadeka/issues/13)

- [ ] В настройках можно выбрать шрифт и размер текста песен. Изменения применяются с сохранением синхронизации.
- [ ] При наличии романизации под оригиналом отображается строка латиницей. Обе строки следуют одним временным отметкам.
- [ ] lrc.red доступен в меню источников. Поиск использует название и исполнителя, а совпадение проверяется по длительности.
- [ ] При наличии таймингов lrc.red плеер отображает построчную или пословную синхронизацию в зависимости от разметки.

[Документация API lrc.red](https://lrc.red/api)

### Локализация интерфейса и английский язык

[Задача #14](https://github.com/starsinc1708/mediadeka/issues/14)

- [ ] Тексты интерфейса, сообщений об ошибках и подписей для экранного диктора вынесены в ресурсы переводов.
- [ ] На русском и английском можно пройти гостевой вход, открыть медиатеку, начать воспроизведение и изменить настройки.
- [ ] Язык можно выбрать в настройках. Выбор сохраняется после перезапуска.
- [ ] Для отсутствующего перевода показывается текст на базовом языке. Формы множественного числа, даты и числа учитывают выбранный язык.
- [ ] В репозитории описано, как добавить перевод и проверить пропущенные строки. Длинные переводы проверены в интерфейсе.
