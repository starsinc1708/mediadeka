## Выпуски на других платформах

После Windows в плане идут Linux и macOS, затем Android и отдельное приложение для Android TV. Первый выпуск каждой платформы охватывает медиатеку, очередь и воспроизведение. Доступность музыкальных сервисов может различаться.

| Платформа | Первый выпуск | Issue |
| --- | --- | --- |
| Linux | Устанавливаемая сборка для Wayland и X11. | [#5](https://github.com/starsinc1708/mediadeka/issues/5) |
| macOS | Первый выпуск для Apple Silicon с панелью «Исполняется». | [#6](https://github.com/starsinc1708/mediadeka/issues/6) |
| Android | Плеер для телефона с фоновым воспроизведением. | [#7](https://github.com/starsinc1708/mediadeka/issues/7) |
| Android TV | Самостоятельный плеер для телевизора. Первый сетевой источник — Jellyfin. | [#8](https://github.com/starsinc1708/mediadeka/issues/8) |
