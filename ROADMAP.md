# Roadmap Mediadeka

## Ближайшие функции

### Трансляция музыки на телевизор

- В меню «Устройство вывода» появляются совместимые телевизоры и ресиверы в домашней сети. Первый сценарий — локальные треки на устройствах с UPnP/DLNA MediaRenderer. [Спецификация MediaRenderer](https://openconnectivity.org/developer/specifications/upnp-resources/upnp/mediaserver4-and-mediarenderer3/)
- Mediadeka показывает имя выбранного устройства и сохраняет очередь. Из плеера доступны пауза, следующий трек и перемотка, когда её поддерживает устройство. При отключении можно продолжить на компьютере с последней известной позиции.
- Следующее расширение — Google Cast для совместимых устройств. Поддержку сетевых источников добавлять по мере проверки каждого адаптера на реальном устройстве. [Google Cast SDK](https://developers.google.com/cast/docs/overview)

### Управление воспроизведением из Windows

- Через системную панель и медиаклавиши можно поставить трек на паузу и переключить его, даже когда Mediadeka свёрнута. В панели видны название, обложка и состояние воспроизведения.

### Автообновление локальной медиатеки

- Выбранные папки можно подключить как постоянные источники. Новые и переименованные файлы появляются после обновления библиотеки. При отключении диска сохраняются плейлисты и история, а после его возврата записи снова доступны.

## Выпуски на других платформах

Сначала настольные версии для Linux и macOS, затем Android и отдельное приложение для Android TV. Первые выпуски каждой версии охватывают медиатеку, очередь и воспроизведение. Доступность подключаемых музыкальных сервисов может различаться по платформам.

- **Linux.** Устанавливаемая сборка с поддержкой Wayland и X11, локальных файлов, выбора аудиовыхода и системных медиаклавиш.
- **macOS.** Первый выпуск для Apple Silicon с локальной медиатекой, выбором аудиовыхода и управлением через системную панель «Исполняется».
- **Android.** Интерфейс для телефона с воспроизведением в фоне и управлением из уведомления и с экрана блокировки. [Фоновое воспроизведение на Android](https://developer.android.com/media/media3/session/background-playback)
- **Android TV.** Самостоятельное приложение с крупным экраном воспроизведения, поиском, очередью и навигацией с пульта. Первый сетевой источник — Jellyfin. Приложение можно использовать без запущенной Mediadeka на компьютере. [Рекомендации Android TV для медиа](https://developer.android.com/media/implement/surfaces/android-tv)

## Следующие функции

- **Непрерывное воспроизведение.** Переходы без пауз в концертных и концептуальных альбомах. Для обычных очередей можно включить плавное сведение соседних треков.
- **Мини-плеер.** Отдельное компактное окно с обложкой, названием, прогрессом и кнопками управления. Размер и положение сохраняются между запусками.
- **Умные плейлисты.** Сохранённые правила по источнику, исполнителю, истории и отметкам «Нравится». Список обновляется по мере изменения медиатеки.
- **Перенос плейлистов.** Экспорт локальных плейлистов в M3U8 с относительными путями. При повторном импорте сохраняются порядок и информация о недоступных файлах.
- **Выравнивание громкости.** Настройка громкости по ReplayGain для треков с подходящими тегами. Режим альбома сохраняет разницу громкости между его композициями.

## Расширение возможностей плеера и медиатеки

1. **Эквалайзер.** Параметрическая настройка звука, сохранённые пресеты и автоматический выбор пресета при смене аудиовыхода.
2. **Таймер сна.** Остановка воспроизведения через заданное время или в конце текущего трека.
3. **Управление из системного трея.** Пауза, переключение треков, возврат к окну и выход из приложения.
4. **Управление другими устройствами через Spotify Connect.** Выбор удалённого устройства, перенос воспроизведения и регулировка его громкости.
5. **Добавление трека в несколько плейлистов.** В одном меню можно изменить отметку «Нравится», добавить трек в нужные плейлисты или убрать его из них.
6. **Приватные плейлисты.** Изменение видимости собственного плейлиста там, где это поддерживает музыкальный сервис. Первый сценарий — Яндекс Музыка.
7. **Статистика прослушивания.** Реальное время воспроизведения по неделям, наиболее прослушиваемые треки и рейтинг исполнителей за выбранный период.
8. **Список «Меньше такого».** Просмотр скрытых треков и исполнителей с отменой отметки там, где её поддерживает сервис.
9. **Настройки шрифта текстов песен.** Отдельный выбор шрифта и размера с сохранением синхронизации при чтении.
10. **Романизация текстов песен.** Дополнительная строка латиницей рядом с оригиналом, когда для песни доступна романизация. Обе строки следуют одним отметкам времени.
11. **Подключение домашних музыкальных серверов по OpenSubsonic.** Первый сценарий — Navidrome с поиском, альбомами, плейлистами и воспроизведением.
12. **Совместное прослушивание.** Закрытая сессия по приглашению, общая очередь и синхронное воспроизведение через собственное подключение каждого участника к музыкальному сервису.
13. **Проверка обновлений из приложения.** Текущая и новая версии, список изменений и проверка подлинности установщика перед запуском. Для сборок из пакетного менеджера доступна штатная команда обновления.
14. **Подключение Apple Music, TIDAL и Deezer.** Поэтапно добавить поиск и воспроизведение для каждого сервиса в пределах возможностей его интеграции.
15. **Поиск текстов треков через lrc.red.** Добавить lrc.red в меню источников текста. Поиск использует название и исполнителя, а совпадение проверяется по длительности записи. При наличии таймингов плеер показывает построчную или пословную синхронизацию. [Документация API lrc.red](https://lrc.red/api)
